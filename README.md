# desafio_teste_batalha_naval

## Especificação do desafio

Batalha naval em tabuleiro **10×10** com a seguinte frota:

| Embarcação | Tamanho |
|------------|--------:|
| Porta-aviões | 5 |
| Encouraçado | 4 |
| Submarino | 3 |
| Destroier ou Hidroavião | 2 |

A implementação deve suportar (conforme regras documentadas nos testes):

- Posicionamento de navios (horizontal/vertical, sem sobreposição, dentro do tabuleiro)
- Disparos, acerto/erro, afundamento e fim de jogo

Código em `src/`; casos de teste em `tests/` (JavaScript + Jest).

## Como executar os testes

```bash
npm install
npm test
```

Modo observação:

```bash
npm run test:watch
```
